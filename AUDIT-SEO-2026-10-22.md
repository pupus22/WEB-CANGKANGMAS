# Hasil revisi SEO, 22 Oktober 2026

## Perubahan

- Tujuh HTML publik dibangun dari data publik Firebase, sehingga judul, isi utama, tautan, foto, dan informasi usaha tersedia sebelum JavaScript berjalan.
- Judul dan deskripsi SEO, canonical, Open Graph, Twitter Card, serta JSON-LD diselaraskan dengan data admin. Foto HORN dan OMEGA menggunakan foto produk, bukan logo.
- LocalBusiness memakai alamat, kontak utama, dan wilayah layanan yang disimpan. Jam yang tidak tersedia tidak direka. Product dan BreadcrumbList ditambahkan pada detail produk.
- Penonaktifan indeks mengeluarkan halaman dari sitemap. Produk HORN/OMEGA yang disembunyikan mendapat noindex pada hasil build. Foto yang dihapus tidak dipulihkan dari aset lama.
- Harga dan status stok tidak disalin ke snapshot HTML. Data langsung Firebase mengisi harga dan Offer saat pemuatan berhasil. Kegagalan menampilkan pesan, tanpa menawarkan harga snapshot lama.
- Gambar lokal memiliki dimensi dan decoding asynchronous. Hero mendapat prioritas tinggi; gambar di bawahnya menggunakan lazy loading. Foto terkompresi dibuat sebagai turunan dan gambar asli tetap disertakan.
- Workflow GitHub membangun dan memublikasikan ulang setiap jadwal 15 menit, push branch utama, atau Run workflow. Perlu aktivasi GitHub Pages sekali; belum dijalankan pada repository pengguna.

- PASS: browser Chromium, tujuh route pada lebar 360, 412, 768, dan 1366 px. Satu H1 per halaman, canonical sesuai route, tanpa overflow horizontal dan tanpa pageerror JavaScript pada skenario yang dijalankan.

- PASS: browser tanpa JavaScript tetap menampilkan H1, konten dan foto HORN; tidak ada harga snapshot.

## Pemeriksaan AntiSlop pada bagian revisi

Arah visual mengikuti desain publik yang sudah disetujui: biru tua/putih, produk dan foto usaha sebagai fokus, layout serta navigasi dipertahankan. Tidak menambah tema, animasi, section pemasaran, ikon, logo, testimoni, atau klaim usaha. ENERGY 2 / RHYTHM 2 / MOTION 1 mengikuti desain yang ada.

- R-02, R-15, R-16 PASS: teks bantuan baru memakai bahasa langsung, tanpa slogan atau buzzword tambahan. Teks lama milik pengelola dipertahankan.
- R-03 PASS untuk viewport yang diuji: tidak ada overflow horizontal pada 28 kombinasi route/lebar.
- R-17, R-18, R-23, R-36, R-38 PASS: konten build berasal dari data publik aktual; tanpa harga, jam, alamat, testimoni, atau aset rekaan.
- R-24, R-26, R-32 PASS untuk kontrol terkait: navigasi, detail produk, salin tautan, galeri dan Escape, serta submit SEO diuji. Tautan eksternal diperiksa tanpa mengirim pesan.
- R-25 PASS untuk pasangan warna dasar yang diuji suite lama: putih/biru tua 13,74:1; abu teks/putih 5,92:1; abu teks/latar muda 5,40:1. Warna CSS tidak diubah. Bukan audit seluruh piksel foto hero.
- R-27 PASS: initial content, loading, empty, missing product, dan error diuji. Harga lama tidak muncul saat error.
- R-33 PASS: perubahan fitur ditulis langsung dalam source. Build menghasilkan HTML dari renderer yang sama, tidak memasang patch CSS runtime.
- R-35 PASS dalam lingkup revisi: build, unit test, regression test, dan browser click-through di atas dijalankan.
- R-37 dan R-31 PASS: mempertahankan komposisi yang disetujui; dimensi gambar untuk stabilitas layout, kompresi untuk mengurangi transfer, metadata untuk identifikasi halaman.
- Purpose-Gate, tema, dan elemen visual baru: tidak ada teknik visual/tema baru yang ditambahkan. Core AntiSlop diperiksa dalam lingkup perubahan, bukan sertifikasi seluruh aplikasi lama.
